## 一、本目录用途

本目录存放各章节的过程截图，作为课程要求的过程证据（实验报告与验收时的"看得见的过程"）。
图片由各人**自行生成、自行提交**到自己的成员分支，支持经理只负责统一命名规则并汇总收集状态，
不代为提交他人的截图，也不改动他人截图文件。

## 二、命名规范

`第X章_姓名_内容.png`，全部使用下划线分隔、章节号用阿拉伯数字，例如：

```text
第1章_宋怀海_git-version.png
第1章_叶凌霄_身份配置.png
第3章_叶凌霄_branch-a.png
第4章_叶凌霄_push.png
```

- `第X章`：对应课程章节号，不加前导零；
- `姓名`：中文姓名，与 README「二、组员表」一致；
- `内容`：这张图证明了什么，用短横线连接的英文或简短中文关键词，避免空格与括号。
