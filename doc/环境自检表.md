## 五、如何逐条复核本表

```console
# 查看远程全部分支（验证每人都有成员分支）
$ git ls-remote --heads origin

# 查看某个成员分支的首个提交（验证确有其人 push）
$ git log --oneline origin/wjh_branch

# 核对提交作者与邮箱（期末逐人核算工作量的依据）
$ git log --all --pretty="%h|%ad|%an<%ae>|%s" --date=short
```
